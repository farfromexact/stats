# rat race 模块口径

`rat race` 模块用于复刻管理透视表的委内分类，并把指定委外账户并列展示。金额使用源表 `全价市值(亿)`，报告月份随页面选择。

## 源字段

月度 snapshot 需要保留以下源字段。旧文件缺少字段时应用会填空，相关记录通常会进入未纳入对账明细。

| 源字段 | 标准字段 |
|---|---|
| 委受托维度 | `mandate_type` |
| 基金账套名称 | `fund_book_name` |
| 分组账套名称 | `group_book_name` |
| 资产大类 | `asset_major_class` |
| 资产分类一级 | `asset_class_level_1` |
| 资产分类二级 | `asset_class_level_2` |
| 资产分类三级 | `asset_class_level_3` |
| 交易策略 | `trade_strategy` |
| 资产分类 | `asset_class` |
| 投资经理 | `manager` |

## 委内五类

委内分类只统计 `mandate_type = 委托资管`。

| 展示分类 | Snapshot 条件 |
|---|---|
| 委内-固收-配置盘 | `asset_major_class = 固收`，`trade_strategy = 配置`，`asset_class` 属于 `存款`、`同业存单`、`政府债`、`金融债`、`企业债`、`固收类保险资管产品` |
| 委内-固收-交易盘 | `asset_major_class = 固收`，`trade_strategy` 含 `交易`，`asset_class` 属于 `同业存单`、`政府债`、`金融债`、`企业债`、`资产支持证券`、`债券型基金`、`固收类保险资管产品` |
| 委内-非标 | `asset_major_class = 固收`，`trade_strategy = 配置`，`asset_class` 属于 `信托计划`、`债权计划`、`资产支持计划`、`持有型不动产ABS` |
| 委内-权益-配置盘 | `asset_major_class = 权益`，`trade_strategy = 配置`，`manager = 鲍淼`，`asset_class = 股票` |
| 委内-权益-交易盘 | `asset_major_class = 权益`，`trade_strategy = 交易`，`asset_class` 属于 `股票`、`股票型基金`、`混合型基金`、`股票型保险资管产品`、`混合型保险资管产品` |

注意：`鲍淼（交易）` 仍归权益交易盘。`交易,流动性` 里的 `固收类保险资管产品` 归固收交易盘。

## 委外四类

委外分类不依赖 `asset_major_class` 和 `trade_strategy`，因为这些账户在 snapshot 中经常未填报；分类主要按 `mandate_type`、`fund_book_name` 和 `asset_class` 判断。

人保、泰康固收仍按固收主资产口径统计。富国、华泰权益为了对齐委托规模和收益透视表，按账户全量口径统计，包含现金、应收、费用、货币基金等流动性调节项。富国在 snapshot 中同时有一条 `富国基金单一计划 / 分红邮储单一委外专户` 顶层产品行，以及 `富国基金中邮1号单一资产管理计划` 底层持仓；模块只纳入底层持仓，顶层产品行进入未纳入明细并标注为重复计算排除。

| 展示分类 | Snapshot 条件 |
|---|---|
| 委外-人保固收 | `mandate_type = 委托人保`，`asset_class` 属于固收主资产：`同业存单`、`政府债`、`金融债`、`企业债`、`资产支持证券`、`债券型基金`、`固收类保险资管产品`、`信托计划`、`债权计划`、`资产支持计划`、`持有型不动产ABS`、`公募REITS` |
| 委外-泰康固收 | `mandate_type = 委托泰康`，`asset_class` 属于上述固收主资产 |
| 委外-富国权益 | `fund_book_name` 含 `富国` 的底层账套全量记录 |
| 委外-华泰权益 | `mandate_type = 委托华泰` 的账户全量记录 |

现金、买入返售、正回购、应收、费用、货币类产品等不进入委内五类、人保固收和泰康固收，会进入未纳入对账明细；但富国、华泰权益账户内的这些科目会纳入对应委外权益分类。

## 展示归并

| Snapshot 资产分类 | 展示明细 |
|---|---|
| 资产支持证券 | 企业债 |
| 债券型基金、固收类保险资管产品 | 固收类基金及产品 |
| 信托计划、债权计划、资产支持计划、持有型不动产ABS | 非标 |
| 股票型基金、混合型基金、股票型保险资管产品、混合型保险资管产品、单一资产管理计划（股票类产品） | 股票型产品 |

## 未纳入原因

未纳入对账明细覆盖所有未进入九类的记录，并额外标注原因。股权/不动产直投通常因为 `asset_major_class` 或 `trade_strategy` 未填报且不是指定委外账户，所以会显示为 `股权/不动产直投，未纳入 rat race 核心分类`。

常见原因包括：

| 原因 | 典型资产 |
|---|---|
| 股权/不动产直投，未纳入 rat race 核心分类 | 股权基金、未上市企业股权、不动产基金、不动产直投、股权计划 |
| 流动性、现金、回购、应收或费用科目 | 活期存款、买入返售、正回购、货币类基金、其他（应收）、其它 |
| 源表缺少资产大类或交易策略 | 部分外部产品、缺省分类 |
| 非委内/指定委外账户 | 非本模块目标委托方或产品账户 |
| 富国顶层产品汇总行，已排除以避免重复计算底层持仓 | `富国基金单一计划 / 分红邮储单一委外专户` |
