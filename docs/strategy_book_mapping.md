# 委内/委外比较模块口径

`委内/委外比较` 模块用于复刻管理透视表的委内分类，并把指定委外账户并列展示。金额使用源表 `全价市值(亿)`，数据时点随页面选择；临时中间版会按完整日期单独标注。

## 源字段

月度 snapshot 需要保留以下源字段。旧文件缺少字段时应用会填空，相关记录通常会进入未纳入对账明细。

| 源字段 | 标准字段 |
|---|---|
| 委受托维度 | `mandate_type` |
| 基金账套名称 | `fund_book_name` |
| 分组账套名称 | `group_book_name` |
| 资产大类 | `asset_major_class` |
| 资产分类一级 | `asset_class_level_1` |
| 资产分类二级 | `asset_class_level_2` |
| 资产分类三级 | `asset_class_level_3` |
| 交易策略 | `trade_strategy` |
| 资产分类 | `asset_class` |
| 投资经理 | `manager` |

## 委内五类

委内分类只统计 `mandate_type = 委托资管`。

| 展示分类 | Snapshot 条件 |
|---|---|
| 委内-固收-配置盘 | `asset_major_class = 固收`，`trade_strategy = 配置`，`asset_class` 属于 `存款`、`同业存单`、`政府债`、`金融债`、`企业债`、`固收类保险资管产品` |
| 委内-固收-交易盘 | `asset_major_class = 固收`，`trade_strategy` 含 `交易`，`asset_class` 属于 `同业存单`、`政府债`、`金融债`、`企业债`、`资产支持证券`、`债券型基金`、`固收类保险资管产品` |
| 委内-非标 | `asset_major_class = 固收`，`trade_strategy = 配置`，`asset_class` 属于 `信托计划`、`债权计划`、`资产支持计划`、`持有型不动产ABS` |
| 委内-权益-配置盘 | `asset_major_class = 权益`，`trade_strategy = 配置`，`manager = 鲍淼`，`asset_class = 股票` |
| 委内-权益-交易盘 | `asset_major_class = 权益`，`trade_strategy = 交易`，`asset_class` 属于 `股票`、`股票型基金`、`混合型基金`、`股票型保险资管产品`、`混合型保险资管产品` |

注意：`鲍淼（交易）` 仍归权益交易盘。`交易,流动性` 里的 `固收类保险资管产品` 归固收交易盘。

## 指定委外账户

委外分类不依赖 `asset_major_class` 和 `trade_strategy`，因为这些账户在 snapshot 中经常未填报；分类主要按 `mandate_type`、`fund_book_name` 和 `asset_class` 判断。

人保、泰康固收仍按固收主资产口径统计。中信建投、中邮证券单一计划归固收盘；华夏基金、国泰海通、大成基金、富国基金、广发基金单一计划归权益盘。华泰、太平资产香港、太保投资香港、国寿富兰克林仍按原账户全量口径统计。

单一委外计划可能同时出现顶层产品汇总行和底层持仓。模块按完整数据时点检查两层的 `full_market_value`：底层有规模时纳入底层并排除顶层；底层规模为零而顶层有规模时改用顶层并排除底层。这样既兼容月底宽表，也兼容 20260716 这类临时快照，同时避免同月多个时点互相污染或规模和收益重复计算。

| 展示分类 | Snapshot 条件 |
|---|---|
| 委外-人保固收 | `mandate_type = 委托人保`，`asset_class` 属于固收主资产：`同业存单`、`政府债`、`金融债`、`企业债`、`资产支持证券`、`债券型基金`、`固收类保险资管产品`、`信托计划`、`债权计划`、`资产支持计划`、`持有型不动产ABS`、`公募REITS` |

## 委外权益持仓证据表

`委外权益持仓（资产证据口径）` 放在委内/委外比较模块下，但不是新的总盘分类。它先按上述规则扫描所有 `strategy_book_scope = 委外` 的记录，再只保留权益资产分类，用来查看委外公司实际持有的权益明细。

权益资产分类固定为：`股票`、`股票型基金`、`混合型基金`、`股票型保险资管产品`、`混合型保险资管产品`、`单一资产管理计划（股票类产品）`、`股权基金`、`未上市企业股权`、`股权计划`。`公募REITS` 暂不纳入本表。

本表沿用资产证据口径展示收益贡献、收益拖累、规模增减和年初持仓变化。聚合时保留 `strategy_book` 和 `strategy_book_display_label`，所以不同委外公司持有同一证券时不会合并。

页面提供 `权益类型` 筛选：`股票` 仅包含 `asset_class = 股票`；`基金及产品` 包含其余权益资产分类。

## 未纳入原因

未纳入对账明细覆盖所有未进入分类的记录，并额外标注原因。股权/不动产直投通常因为 `asset_major_class` 或 `trade_strategy` 未填报且不是指定委外账户，所以会显示为 `股权/不动产直投，未纳入委内/委外比较核心分类`。

常见原因包括：

| 原因 | 典型资产 |
|---|---|
| 股权/不动产直投，未纳入委内/委外比较核心分类 | 股权基金、未上市企业股权、不动产基金、不动产直投、股权计划 |
| 流动性、现金、回购、应收或费用科目 | 活期存款、买入返售、正回购、货币类基金、其他（应收）、其它 |
| 源表缺少资产大类或交易策略 | 部分外部产品、缺省分类 |
| 非委内/指定委外账户 | 非本模块目标委托方或产品账户 |
| 某策略盘顶层产品汇总行，已排除以避免重复计算底层持仓 | 当月底宽表的底层持仓已有非零规模 |
| 某策略盘底层持仓行规模为零，已改用顶层产品汇总行 | 当临时快照只在顶层产品行填报规模 |
